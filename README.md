# weeky-weeky
Week Number and Weather Widget for Windows Powershell

# Week + Weather Widget (PowerShell)

Small floating widget showing:
- Week number
- Current temperature
- Weather icon

## Features
- Borderless window
- Semi-transparent
- Draggable
- Snaps to taskbar (right click)
- Updates weather every 10 min
